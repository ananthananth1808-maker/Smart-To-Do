# Smart To-Do – Productivity Management Application

A responsive and user-friendly task management web application built using HTML, CSS and JavaScript. Smart To-Do helps users organize their daily activities, manage priorities, track completed tasks and maintain productivity.

## 🚀 Features

- **Add Tasks:** Create new tasks with titles and descriptions.
- **Edit Tasks:** Update existing task information.
- **Delete Tasks:** Remove unwanted tasks.
- **Task Completion:** Mark tasks as completed or pending.
- **Task Categories:** Organize tasks into Personal, Work and Study.
- **Priority Management:** Assign High, Medium or Low priority.
- **Due Dates:** Set deadlines for individual tasks.
- **Search Tasks:** Quickly find tasks using the search feature.
- **Category Filtering:** Filter tasks based on categories.
- **Status Filtering:** View all, pending or completed tasks.
- **Dashboard Statistics:** Track total, pending and completed tasks.
- **Local Storage:** Automatically save tasks in the browser so they remain available after refreshing the page.
- **Responsive Design:** Use the application on desktop and mobile devices.


### 2. Navigate to the project folder

```bash
cd Smart-Todo
```

### 3. Open the project

Open `index.html` using Visual Studio Code and launch it with the Live Server extension.

Alternatively, open the HTML file directly in your browser.

## 💻 How to Use

1. Open the Smart To-Do application.
2. Click the **Add Task** button.
3. Enter the task title and description.
4. Select a category and priority.
5. Set a due date if required.
6. Click **Save Task**.
7. Edit, delete or mark tasks as completed whenever needed.
8. Use search and filters to organize your tasks.

Your tasks are automatically stored in browser LocalStorage.

## 💾 Data Storage

This application uses the browser's LocalStorage API to store task information.

- No database installation is required.
- Tasks remain saved after refreshing the page.
- Data is stored locally in the browser.
- Clearing browser storage or site data may remove saved tasks.
